# Melissa Rodríguez — Portfolio website

A responsive, one-page portfolio built with plain HTML, CSS and JavaScript. No build tools, frameworks, or hosting fees required.

## Publish with GitHub Pages

1. Create a new GitHub repository (for example, `portfolio`).
2. Upload **the contents of this folder** to the repository root (`index.html`, `style.css`, `script.js`, `assets/`, and the PDF files).
3. In your repository, go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. Once published, GitHub will show your site URL in Settings → Pages. The usual URL format is `https://YOUR-USERNAME.github.io/portfolio/`.

## Customize

- Edit `index.html` to change copy, email, project names, and experience.
- Edit `style.css` for fonts, colors, spacing and layout.
- Replace image files inside `assets/` to update project visuals. These visuals are rendered from the portfolio PDF, not AI-generated mockups.
- Replace `Melissa_Rodriguez_Resume.pdf` to update the downloadable résumé.
- Replace `Melissa_Rodriguez_Full_Portfolio.pdf` to update the full PDF link. The site uses the optimized full-portfolio PDF for faster downloads; verify it contains any recent changes you need before sharing.

**Note:** Google Fonts are loaded from the web. If unavailable, system fonts are used. All other site assets are local.
